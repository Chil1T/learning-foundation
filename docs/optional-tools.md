# 可选工具协同与扩展 (Optional Tools)

Learning Foundation 本身秉持**极简主义**，仅通过纯文本与 Markdown 即可完成全部认知辅导工作。

但如果你有更丰富的多模态、学术排版或任务管理需求，套件可与以下优秀的开源及商业工具实现强强联合：

---

## 1. 复杂文献与公式解析：MinerU
研读顶级期刊（如 IEEE、Nature、arXiv）中的学术论文时，PDF 双栏排版和多行数学公式往往容易被普通工具截断。
* **推荐方案**：使用 [MinerU](https://github.com/opendatalab/MinerU) 将论文 PDF 转换为高质量的高精度 Markdown。
* **协同方式**：`paper-deep-reader` 能够直接读取解析后的清晰 Markdown，精准抓取推导细节。

---

## 2. 本地双链知识库：Obsidian
* **推荐方案**：将 Learning Foundation 技能直接部署在你的 [Obsidian](https://obsidian.md) 笔记库（Vault）中。
* **协同方式**：
  - 智能体通过 Markdown 链接关联你的已有随手记与学习总结；
  - 绝不改动你的主题配置、插件与个人文件夹；
  - 白板 (Canvas) 与手绘图均可作为推导的图示载体。

---

## 3. 互动式幻灯片课件：Slidev
* **推荐方案**：如果你需要为组会、研讨班或公开技术分享制作精美的讲义，可以使用 [Slidev](https://sli.dev)。
* **协同方式**：让智能体将 `concept-tutor` 或 `research-meeting-prep` 梳理出的核心推导逻辑，按 Slidev 格式直接导出为可演示的现代幻灯片。

---

## 4. 行动检查点管理：Todoist
* **推荐方案**：如果你习惯使用任务管理软件（如 [Todoist](https://todoist.com)）。
* **协同方式**：`learning-plan-designer` 规划出学习里程碑后，你可以授权将行动待办事项同步到 Todoist，而详细的学术推导与解题过程依然留在本地笔记库中。
