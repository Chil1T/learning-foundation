# 客户端兼容与部署指南 (Compatibility)

Learning Foundation 严格遵循行业通用的 [Agent Skills 规范](https://agentskills.io/specification)，在所有遵循该规范的现代 AI 智能体客户端中均可即插即用。

---

## 💻 常见客户端接入指引

### 1. OpenAI Codex
依据 Codex 的项目扩展标准，项目级技能存放在当前工作区的 `.agents/skills/` 目录下：
* 存放路径：`<你的项目根目录>/.agents/skills/<技能名称>/`
* 刷新方式：在客户端重新加载工作区，在对话中即可通过自然语言唤醒。

### 2. Claude Code
Claude Code 原生支持项目技能发现：
* 存放路径：支持放置于项目的技能目录或全局自定义技能库。
* 唤醒方式：直接在对话中输入技能名称即可自动触发执行。

### 3. Google Antigravity
Google Antigravity 拥有开箱即用的多智能体与技能发现机制：
* 存放路径：支持放入工作区内置技能目录。
* 唤醒方式：通过系统提示词或对话自然触发。

### 4. OpenCode / Cursor / 更多 Agent 客户端
只要客户端支持读取 Markdown 提示词工作流：
* 你可以直接将某个技能目录（例如 `skills/concept-tutor/SKILL.md`）作为自定义 Prompt 规则导入；
* 不需要做任何代码适配，因为每个技能本身就是清晰的认知工作流规范。

---

## 🛠️ 优雅降级设计 (Graceful Degradation)

在各种受限环境下，套件均具备出色的弹性表现：

* **无文件系统写入权限时**：智能体自动降级为“纯对话交付模式”，在聊天中给出建议与推导，绝不强行报错。
* **无外部网络环境时**：所有技能均为纯离线 Prompt 逻辑，无任何云端依赖，离线断网依然完美运行。
* **缺少某个关联技能时**：当前技能会自动在自身职责边界内尽力完成任务，绝不抛出“必须先安装某某依赖”等阻断提示。
