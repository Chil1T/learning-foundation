# 来源与许可边界 (Provenance & Licensing)

## 项目背景与演化

**Learning Foundation** 源于高强度真实科研学习与前沿技术攻坚中提炼出的一组方法论。它将长期实践中验证有效的认知规律、精读原则与交互范式，沉淀为标准、通用的 **Agent Skills** 开源套件。

项目不包含任何个人私有笔记、未公开学术论文、敏感账户配置或私人历史，是一套完全独立的开源基座。

当前版本请以根目录 [VERSION](../VERSION) 为准。

---

## 规范与标准依据

套件的设计与元数据接口遵循以下行业开放标准：
* [Agent Skills 规范](https://agentskills.io/specification)：标准技能目录结构、元数据规范与提示词格式。
* [Vercel Skills 规范](https://github.com/vercel-labs/skills)：现代智能体生态的发现与安装器接口。
