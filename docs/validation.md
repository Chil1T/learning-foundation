# 工程验证与质量保障 (Validation & QA)

Learning Foundation 在发布前均需通过严格的自动化测试与静态合规审计，确保每个技能单元都具备高度的便携性与安全性。

---

## 🧪 自动化测试套件

项目自带基于 Python 3.10+ 标准库编写的自动化回归测试套件（位于 `tests/` 目录），无需安装第三方依赖即可直接运行：

```sh
python -m unittest discover -s tests -v
```

测试套件重点覆盖 12 项关键边界用例：
* **单技能完全自洽性**：确保每个技能内部自包含，不越界依赖相邻技能或外层文档；
* **规范元数据验证**：确保每个 `SKILL.md` 的 YAML 元数据格式合规，`name` 与目录严格一致；
* **链接完整性检查**：严格断言所有相对 Markdown 链接在打包范围内均可有效解析；
* **敏感信息防御**：确保无本地绝对路径、私钥、API 令牌或未完成占位标记误入打包目录；
* **归档完整性校验**：通过 CRC 与 SHA-256 双重指纹校验发布归档文件的安全与一致性。

---

## 🔍 发布前静态审计

在构建发布版本前，运行以下静态审计脚本对全库进行健康检查：

```sh
python tools/check_release.py
```

该工具执行严格的白名单准入控制与安全模式扫描，确保交付给社区的是一份极其纯净、开箱即用的优质资产。
