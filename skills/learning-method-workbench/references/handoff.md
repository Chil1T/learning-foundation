# 最小交接

只有跨任务、跨技能或中断时确有帮助才创建交接，不要求每次输出完整表单。内容可在一小段话中表达：

- 当前目的与已授权范围。
- 正在用的资料、版本或位置；相关本地方法入口。
- 实际做过什么；用户原话、AI 解释与状态判断分别是什么。
- 未解问题、需要保留的停点与下一步。
- 本次交付是否已写入，效果是否已有观察。

接手者从这个停点继续；无需重跑工作区初始化、重复扫描所有历史或重问已明确授权。缺少某份材料时只缩小相应结论，不把未知变成“未完成”。

例如，一次方法改进结束后可交接“已将核对移到段落结束，未改用户旧作答；下一次从原文指定位置继续，观察用户反馈”。这是交接方式示例，不是实际用户状态。

若没有专门的教学、研究或同步技能，当前智能体仍可按已知目标直接工作。不要以调用其他技能为当前交付的隐藏必要条件。
