# 可合并的学习协作片段

这是候选规则片段。仅在用户授权后，选择与本地目标有关的内容合并到已有项目入口；不是用来整体覆盖入口的文件。路径映射应使用现有工作区实际位置。

- 按当前目的和授权工作。只读讨论不自动写入；已授权的范围内直接推进。
- 区分原始来源、个人笔记、用户原话、AI 解释、计划和状态判断。原文和个人笔记只在明确授权范围内修改。
- 结论与实际证据相称。区分阅读、自述、受提示复述、独立新例表现与研究贡献；保留未知和判断修订依据。
- 在必要停顿保留目标、来源位置、进展、未解问题与下一步。补前置知识时保留原任务返回点。
- 方法可按当前目标和反馈调整；在授权范围内窄修，保留理由与必要检查，不自动自我改写。
- 语言、排版、教学顺序、目录和工具遵循本地需要。安装技能不等于采纳全部默认。

按需补充：当前使用的方法入口、实际资料与状态位置、允许写入的范围、项目自己的偏好。
